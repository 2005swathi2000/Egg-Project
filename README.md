# 🥚 Egg Vending Machine Web Application

A modern, responsive Next.js web application for an automated Smart Egg Vending Machine system. Live deployed on Vercel.

🌐 **Live Application**: [https://egg-vending-machine.vercel.app](https://egg-vending-machine.vercel.app)

---

## 📌 Project Overview

**Egg-Project** is an interactive digital storefront and inventory management interface for smart egg vending machines. Customers can select egg quantities (organic, brown, white, free-range), view real-time pricing and fresh stock availability, and process seamless digital payments.

---

## ✨ Features

- **🛒 Product Selection**: Browse fresh egg categories with dynamic quantity pickers.
- **📊 Real-time Stock Tracking**: View live machine inventory levels and fresh batch dates.
- **💳 Instant Checkout Simulator**: Seamless payment flow integration with QR code and card support.
- **📱 Mobile Responsive**: Built with Next.js and Tailwind CSS for mobile and desktop screens.
- **⚡ High Performance**: Fast server-side rendering and static optimization via Next.js App Router.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 15+](https://nextjs.org/) (App Router & React 19)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Deployment**: [Vercel](https://vercel.com/)

---

## 🚀 Local Development Setup

### 1. Clone the Repository
```bash
git clone https://github.com/2005swathi2000/Egg-Project.git
cd Egg-Project
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.
